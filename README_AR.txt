مشروع لعبة أبطال المعرفة - الإصدار الثاني

المشروع يحتوي على نسخة اللعبة الثانية كما هي داخل تطبيق Android WebView.

طريقة إنشاء APK بدون تثبيت Android Studio:
1) فك ضغط ملف ZIP على الكمبيوتر.
2) افتح github.com وأنشئ حسابًا أو سجّل الدخول.
3) أنشئ Repository جديدًا باسم abtal-almaarefa، واجعله Public أو Private حسب رغبتك.
4) ارفع محتويات المجلد abtal_android_project إلى جذر المستودع (لا ترفع المجلد الخارجي نفسه).
   مهم: ارفع المجلد المخفي .github أيضًا؛ بداخله ملف تشغيل البناء التلقائي.
5) بعد اكتمال الرفع، افتح تبويب Actions في المستودع.
6) اختر Build Android APK ثم اضغط Run workflow إذا لم يبدأ البناء تلقائيًا.
7) انتظر حتى تظهر علامة النجاح الخضراء، ثم افتح عملية البناء نفسها.
8) انزل إلى قسم Artifacts واضغط Abtal-Almaarefa-APK لتنزيل APK.
9) فك ضغط الملف الذي تم تنزيله، وستجد APK بداخله. انقله إلى هاتف Android وثبّته بعد السماح بالتثبيت من هذا المصدر.

ملاحظات:
- البناء يتم على خوادم GitHub Actions؛ لا يحتاج Android Studio على اللابتوب.
- لا تشارك كلمة مرور حسابك أو أي رموز تحقق مع أي شخص.
- هذا Debug APK للتجربة والتثبيت اليدوي، وليس إصدارًا موقّعًا للنشر على Google Play.
- ملف البناء يستخدم Java 17 وGradle 8.9 وAndroid Gradle Plugin 8.7.3.


تحديث إضافي: تمت إضافة أيقونة أبطال المعرفة وزر لسماع أصوات الحيوانات. أصوات الحيوانات تُحمّل عبر الإنترنت من SFXMint بترخيص CC0 1.0، لذلك يلزم اتصال بالإنترنت لتشغيلها.
